## 三、延迟：60ms 还是 200ms，取决于用户在国内哪里

首尔到中国大陆的物理距离摆在那里，平均延迟多在 50~80ms。但“平均”这个词会骗人，三网的实际走向完全不同：

- **电信**：走 CN2 的方案最好，实测能压到 30ms 上下，晚高峰相对稳。
- **联通**：对接 LG U+ 或走 AS4837 骨干，全国延迟比较均匀，通常落在 30~80ms。
- **移动**：走 CMI，经香港回内地。南方移动 50~65ms 很舒服，**北方移动可能绕出 200ms 以上的跳变**。

没有一条线路对全国三网都最优。买之前值得做的功课是：找商家要测试 IP，从自己所在的省份、自己的运营商 ping 一遍，最好在晚上八九点再 ping 一次。白天 40ms、晚上 300ms 的机器，测速图好看，用起来难受。

顺带说一个容易忽略的点：韩国机房到国内的延迟，跟你本机到机房内网的 ping 完全是两回事。看到“机房内 260ms”这类数字不用慌，那测的是全球节点。

## 十、常见问题

**韩国VPS需要备案吗？**
不需要。境外机房不涉及国内备案流程，但如果域名解析过去、用户主要在国内，访问速度完全取决于线路质量。

**韩国原生 IP 一定能解锁 Netflix 韩国区和 ChatGPT 吗？**
不一定。原生 IP 只说明注册地和地理位置在韩国，平台还看 IP 的历史行为、是否被标记为数据中心。同一个商家不同 IP 段，测试结果都可能不一样，所以先月付实测。

**1核1G 够用吗？**
跑代理、轻量 Bot、静态小站够。跑 Windows、多容器 Docker、数据库，1G 会明显吃紧，2G 起步更稳。

**流量“双向计算”是什么意思？**
入站加出站合计。做中转、挂载、同步备份这类上下行都跑的用途，实际消耗会比单向快一倍，选套餐时要留出余量。

**韩国和香港怎么选？**
要低延迟选香港，10~30ms 是首尔给不了的；要韩国 IP、覆盖东北亚、做韩国区业务选首尔。

**要不要现在就上年付？**
不建议第一次就年付。先用月付确认线路走向、IP 属性、晚高峰表现，三项都满意再用年付拿折扣。年付省下的钱，抵不过一次买错的损失。

**还能加购 IP 吗？**
多数商家支持，价格按类型分层，普通 IP、原生 IP、住宅 IP 各有各的价，加购前先问清是不是同段、能不能换。
